# 3D body model

`body.glb` is generated by [`tools/3d/build_model.py`](../../tools/3d/build_model.py) from
**BodyParts3D, © The Database Center for Life Science, licensed under
[CC Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/)**
(https://dbarchive.biosciencedbc.jp/en/bodyparts3d/).

Changes made to the original data: the meshes were grouped into the app's body parts,
simplified (decimated), re-centred and converted to metres. The skin was given swim shorts:
the hip area was smoothed and flattened, and is marked so the app can colour it. The result
is stored as quantized glTF binary.
